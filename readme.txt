== Description ==

CS Live Chat یک پلاگین چت زنده کامل و حرفه‌ای برای وردپرس است.

ویژگی‌ها:
* ویجت شناور زیبا با انیمیشن
* چت دوطرفه بین کاربر و ادمین
* فرم قبل از چت (نام و ایمیل)
* آپلود فایل و تصویر
* ایموجی پیکر
* صدای نوتیفیکیشن
* نوتیفیکیشن ایمیل و مرورگر
* پاسخ خودکار
* داشبورد آمار
* خروجی CSV
* مسدودسازی کاربران
* حالت تاریک
* امتیازدهی کاربران
* و...

== Installation ==

1. فایل زیپ را در مسیر wp-content/plugins/ آپلود کنید
2. از پیشخوان وردپرس پلاگین را فعال کنید
3. به منوی "چت زنده CS" > "تنظیمات" بروید و تنظیمات را انجام دهید
