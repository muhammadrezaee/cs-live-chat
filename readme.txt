سیستم چت زنده حرفه‌ای و پیشرفته برای وردپرس - محصول codsoft.ir

== Description ==

پلاگین **CS Live Chat** یک سیستم چت زنده کامل، حرفه‌ای و زیبا برای وردپرس است که به شما امکان می‌دهد با مشتریان و بازدیدکنندگان سایت خود به صورت لحظه‌ای در ارتباط باشید.

این پلاگین با طراحی مدرن، رابط کاربری زیبا و امکانات پیشرفته، تجربه‌ای عالی برای هم مدیران سایت و هم کاربران فراهم می‌کند.

🌟 **ویژگی‌های کلیدی:**

* **ویجت شناور زیبا** با انیمیشن‌های حرفه‌ای و قابل سفارشی‌سازی
* **چت دوطرفه** بین کاربر و ادمین در زمان واقعی
* **فرم قبل از چت** برای دریافت نام و ایمیل کاربر
* **آپلود فایل** با کنترل کامل ادمین روی فرمت‌ها و حجم
* **ایموجی پیکر** با بیش از ۱۶۰ ایموجی
* **صدای نوتیفیکیشن** برای اطلاع از پیام‌های جدید
* **نوتیفیکیشن ایمیل** با قالب زیبا و حرفه‌ای
* **نوتیفیکیشن مرورگر** حتی وقتی تب بسته است
* **پاسخ خودکار** هوشمند با تاخیر قابل تنظیم
* **تایپینگ ایندیکیتور** مانند واتس‌اپ
* **وضعیت آنلاین/آفلاین** ادمین
* **داشبورد آمار** با نمودارهای میله‌ای و دایره‌ای
* **خروجی CSV** از تاریخچه چت‌ها
* **مسدودسازی کاربران** مزاحم
* **امتیازدهی** به پشتیبانی
* **حالت تاریک** (Dark Mode)
* **کاملاً ریسپانسیو** و سازگار با موبایل
* **چند زبانه** و قابل ترجمه

🎨 **طراحی و ظاهر:**

* رابط کاربری مدرن با گرادیانت‌های زیبا
* انیمیشن‌های نرم و حرفه‌ای
* قابل سفارشی‌سازی کامل (رنگ‌ها، لوگو، آواتار)
* سازگار با تمام قالب‌های وردپرس

 **امنیت:**

* استفاده از Nonce برای جلوگیری از حملات CSRF
* Sanitization و Validation کامل داده‌ها
* کنترل دسترسی برای ادمین
* محافظت در برابر SQL Injection

 **سازگاری:**

* سازگار با آخرین نسخه وردپرس
* تست شده روی PHP 7.4 و بالاتر
* کار می‌کند با تمام مرورگرهای مدرن
* بهینه‌سازی شده برای موبایل و تبلت

== Installation ==

1. فایل زیپ پلاگین را از پیشخوان وردپرس > افزونه‌ها > افزودن > بارگذاری افزونه آپلود کنید
2. پس از آپلود، پلاگین را فعال کنید
3. به منوی **"چت زنده CS"** در پیشخوان وردپرس بروید
4. وارد بخش **"تنظیمات"** شوید و تنظیمات مورد نظر خود را انجام دهید
5. آدرس سایت، لوگو، رنگ‌ها و سایر تنظیمات را پیکربندی کنید
6. ذخیره کنید و از چت زنده لذت ببرید! 

**نصب دستی:**

1. پوشه `cs-live-chat` را در مسیر `wp-content/plugins/` آپلود کنید
2. از پیشخوان وردپرس > افزونه‌ها، پلاگین را فعال کنید
3. تنظیمات را انجام دهید

== Frequently Asked Questions ==

= آیا پلاگین رایگان است؟ =
بله! CS Live Chat کاملاً رایگان است و می‌توانید از تمام امکانات آن بدون هیچ هزینه‌ای استفاده کنید.

= آیا نیاز به API یا سرویس خارجی دارد؟ =
خیر! این پلاگین کاملاً مستقل است و نیازی به هیچ سرویس خارجی یا API ندارد. تمام داده‌ها در دیتابیس سایت شما ذخیره می‌شوند.

= آیا می‌توانم رنگ‌ها را تغییر دهم؟ =
بله! از بخش تنظیمات می‌توانید رنگ اصلی و ثانویه پلاگین را به دلخواه تغییر دهید.

= آیا کاربران می‌توانند فایل ارسال کنند؟ =
بله! با فعال‌سازی آپلود فایل از تنظیمات، کاربران می‌توانند فایل ارسال کنند. شما می‌توانید فرمت‌های مجاز و حداکثر حجم را مشخص کنید.

= آیا نوتیفیکیشن ایمیل ارسال می‌شود؟ =
بله! وقتی پیام جدیدی دریافت می‌شود، یک ایمیل زیبا با جزئیات کامل برای ادمین ارسال می‌شود.

= آیا پلاگین ریسپانسیو است؟ =
بله! ویجت چت کاملاً ریسپانسیو است و در تمام دستگاه‌ها (موبایل، تبلت، دسکتاپ) به درستی نمایش داده می‌شود.

= چگونه می‌توانم پشتیبانی بگیرم؟ =
برای دریافت پشتیبانی و گزارش باگ، به وبسایت ما به آدرس [codsoft.ir](https://codsoft.ir) مراجعه کنید.

= آیا می‌توانم پلاگین را ترجمه کنم؟ =
بله! پلاگین از چند زبانه پشتیبانی می‌کند و می‌توانید آن را به هر زبانی ترجمه کنید.
